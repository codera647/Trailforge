# Change log

## 0.1.0a1

First public MIT alpha candidate.

- SDK-free, independently installable base package with bounded Goal/Task/Harness execution, SQLite journals, content-addressed evidence and durable recovery.
- Eight-command offline Review CLI with ten original Python/JavaScript/TypeScript fixtures and explicit unsupported/partial coverage.
- Trusted-host Develop profile with bounded rounds, candidate/check hashes and resumable handoff.
- Exact approvals and conservative simulated publication reconciliation, including uncertain outcomes.
- Permission-bound retrieval and allowlisted telemetry ports; optional pinned LangGraph scheduling.
- Optional PostgreSQL legacy Review authority, fenced leases, shared integer mock-unit budgets, dispatch and broker recovery. Generic execution and CLI remain SQLite.
- Digest-pinned Linux container runner with resource limits and five real isolation boundary cases.
- Installed-wheel Linux/Windows Python 3.11/3.13 conformance, original recovery examples, strict suite receipts and explicit distribution inventories.

This is an alpha, with no stable API, live model-quality, actual customer publication or production certification claim. Applied migrations and existing protocol meanings are preserved. See [release status](docs/release-status.md).
